# Diplom_2: API-тесты Stellar Burgers

Автотесты пяти эндпоинтов по [документации API](https://code.s3.yandex.net/qa-automation-engineer/python-full/diploma/api-Stelar_Burger_10.25.pdf?etag=3584917d935c90b69cb3ffaff58d4f34): регистрация, вход, изменение профиля, создание заказа и получение заказов пользователя.

## Запуск

Создайте виртуальное окружение, установите зависимости из `requirements.txt` и выполните:

```bash
.venv/bin/python -m pytest
```

Результаты Allure записываются в `allure-results/`. Для просмотра отчёта при установленной Allure CLI:

```bash
allure serve allure-results
```

По умолчанию тесты обращаются к `https://stellarburgers.education-services.ru` — адресу из документации API. Если подтверждён другой адрес API, его можно указать через переменную окружения `STELLAR_BURGERS_URL`. Тестовые пользователи создаются с уникальными адресами и удаляются фикстурой после теста. API не предоставляет метода удаления заказов; тесты заказов используют временных пользователей и проверяют заказ по его номеру.

В `tests/` находятся только тесты и фикстуры. Запросы к API собраны в `api_client.py`, ожидаемые сообщения об ошибках — в `data.py`, генерация уникальных данных — в `helpers.py`.

Проверка создания заказа без авторизации ожидает `401` согласно требованию авторизации на странице 5 документации API.
